# Bilan Counter — Brand Asset Upload

Temporary staging folder for the original Bilan branding package.

Upload the 59 source assets here when ready. Keep the original filenames produced by the flat-folder collection macro (folder names joined with double underscores, for example `android__res__mipmap-mdpi__ic_launcher.png`).

## Processing notes

- This is an asset staging area, not the final Android resource structure.
- Do not rename or edit the files before uploading.
- After the assets are available, they will be inspected and sorted into the correct Android resource directories.
- Only assets needed for the agreed branding stages will be integrated initially: app icon, light/dark splash, and app header.
- Preserve the existing application ID, app data, and functionality.
- Do not put secrets, credentials, or unrelated files here.

The upload folder is intentionally tracked with this README because Git does not preserve empty directories.
