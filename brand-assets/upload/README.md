# Bilan Counter — Brand Asset Upload

This folder is reserved for the original Bilan Counter branding package.

Upload the 59 gathered files here in a single flat folder. Keep the source folder path in each filename using double underscores (`__`) so duplicate Android resource filenames remain distinct.

Examples:
- `android__res__mipmap-mdpi__ic_launcher.png`
- `android__res__mipmap-hdpi__ic_launcher.png`
- `app-ui__header-logo-horizontal-dark.png`

These are source assets only. They will be reviewed and reorganized into the appropriate Android resource directories before integration. Existing app resources and functionality must be preserved.
